# SNN-JEPA 研究计划

> 本文档是项目的权威研究计划，记录论文定位、假设、贡献清单、缺口分析与战略决策。
> 更新日期：2026-09-27。

## 1. 项目定位

在脉冲神经网络（SNN）中实现 JEPA，系统检验**潜空间预测**是否比**输入空间重建**（MAE）产生更接近生物皮层的神经表征。

**核心叙事：Biologically-Grounded Anti-Collapse** —— JEPA 为防表征坍塌引入的人工技巧，在皮层中都有内源对应物：

| 人工技巧 | 生物内源机制 | 假设 |
|---|---|---|
| 方差正则（VICReg/SIGReg） | 发放率稳态（synaptic scaling） | H2' |
| 协方差去相关 | 突触缩放 + 侧向抑制 | H5 |
| stop-gradient / EMA | 不应期梯度门控 | H4' |

## 2. 论文目标与定位

- **首发目标**：CCN（Conference on Cognitive Computational Neuroscience）/ COSYNE——计算神经科学社区对「SNN + JEPA + 神经可预测」接受度高。
- **升级目标**：NeurIPS / ICLR（ML 社区）或 eLife / PLOS Computational Biology（计算生物）。
- **核心风险**：审稿人第一问「为什么不用 ANN？」——必须用**能量分析与生物机制**给出硬证据，而非仅靠叙事。

## 3. 核心假设

- **H1（修正 2026-09-27）**：在有效抗坍塌机制下，SNN-JEPA 的表征质量与神经预测精度优于 SNN-MAE。（阶段 1 实证：未修复的 JEPA 线性探测 32.53% < MAE 43.93%，主因是维度坍塌 srank=1.0）
- **H2'**：发放率稳态（synaptic scaling）可等价替代方差正则防坍塌，稳态强度与有效秩单调相关。
- **H4'**：不应期梯度门控可替代 EMA + stop-gradient，效果取决于不应期时间常数 τ_ref。
- **H5**：突触缩放 / 侧向去相关可等价替代协方差正则项。
- **H6（新增）**：SNN-JEPA 在相近表征质量下，能耗（SynOps）显著低于 ANN-JEPA。

## 4. 贡献清单

1. **SNN-JEPA 框架**：脉冲编码器 + 潜空间预测目标。
2. **生物内源抗坍塌机制（核心 novelty）**：发放率稳态、突触缩放/侧向去相关、不应期梯度门控，作为 VICReg/SIGReg 与 stop-gradient 的生物可行替代。
3. **能量/效率分析（必做）**：spike 计数、SynOps、能耗对比 ANN-JEPA。
4. **神经可预测性验证**：Allen Brain Observatory → NSD/Algonauts。
5. **脉冲表征的高斯性理论检验**：对接 SIGReg 的各向同性高斯前提（无论成立与否均为贡献）。

## 5. 三个结构性缺口与应对

| 缺口 | 应对 |
|---|---|
| ① 为什么用 SNN（缺硬论证） | 能量/效率分析（SynOps vs ANN） |
| ② spiking 是否有真实意义（时间维度未用） | 时序主线（V-JEPA / DVS），作为后续第二论文 |
| ③ novelty 硬度不足 | 生物机制从「loss 映射」升级为「可塑性规则」 |

## 6. 实验基线清单（扩充）

- SNN-JEPA（主目标）、SNN-MAE（对照）
- **ANN-JEPA**（同结构 ANN 编码器，隔离 spiking 的贡献）
- **SNN-VICReg**（隔离「JEPA 预测」vs「VICReg 正则」的贡献）
- **随机初始化**（性能下界）
- **非脉冲线性编码器对照**（隔离脉冲动力学的贡献）
- 所有实验 **≥3 个随机种子**，报告均值 ± 方差

## 8. 战略决策（2026-09-27 定）

- **当前主线**：生物可塑性规则做硬（P1）+ 能量分析（P0）+ 多基线/多种子（P0）。
- **后续**：时序主线（第二篇论文）、神经可预测做深。
- **抗坍塌机制实现顺序**：发放率稳态（B）→ 突触缩放/去相关（C）→ 不应期梯度门控（A）。
- **算力**：AutoDL 云 GPU（CUDA 12.1 + PyTorch 2.3.0 + SpikingJelly 0.0.0.0.14）。
- **神经数据**：Allen 先行 → NSD/Algonauts。

## 9. 阶段规划

- **阶段 0**：环境与复现（环境已就绪；复现锚点 = 图像 JEPA）
- **阶段 1**：基线搭建 + **多基线 + 多种子 + 能量分析**（进行中）
- **阶段 2**：抗坍塌机制开发与消融 + **生物可塑性规则严格实现** + 高斯性检验
- **阶段 3**：神经数据验证（Allen → NSD）+ RSA + 扰动鲁棒性
- **阶段 4**：论文产出（CCN/COSYNE 首发，再升级）

## 10. 实验结果记录（持续更新）

### 阶段 1（2026-09-27，CIFAR-10，100 epoch，单 seed）

| 模型 | 线性探测 | eff_rank | srank | 结论 |
|---|---|---|---|---|
| SNN-JEPA (VICReg) | 32.53% | 27.6 | 1.0 | 维度坍塌，表征受损 |
| SNN-MAE | 43.93% | 260.6 | 1.7 | 高秩但冗余 |

**关键发现**：未修复的 JEPA 在脉冲域发生维度坍塌（srank=1.0），线性探测低于 MAE。这证明「JEPA 比 MAE 更容易坍塌」，为抗坍塌机制（SIGReg/生物机制）提供强动机。H1 已修正为条件性表述。

**阶段 2 优先路线**：① 实现 SIGReg 简版，把 JEPA 的 srank 从 1.0 拉起；② 对比修复后 JEPA vs MAE；③ 实现生物机制（发放率稳态/突触缩放/不应期门控）作为 SIGReg 的生物替代。

## 11. 学习机制讨论：坍塌诊断（核心维度，2026-09-27 新增）

**项目立意**：JEPA 的潜空间预测学习机制与生物预测学习机制存在共通性（区别于 LLM/重建范式的"预测下一 token / 重建像素"），以 SNN 实现这一共通性。这是项目区别于"把 JEPA 套到 SNN"的灵魂。

**诊断维度**（把「JEPA 效果不佳」转化为「机制理解」的科学贡献）：

1. **坍塌根源定位**：ANN-JEPA（非脉冲编码器，同结构）对照，区分「JEPA 目标本身」vs「脉冲计数表征」对 srank=1.0 的各自贡献；
2. **VICReg 强度消融**：λ_cov / λ_std 对 srank 与线性探测的影响曲线；
3. **主导维度分析**：坍塌主方向的语义内容、各维度方差分布（诊断"哪些信息被保留/丢失"）；
4. **预测损失与坍塌的关系**：pred=0.023 是否源于 target 嵌入低秩。

**价值**：上述诊断构成论文「学习机制」讨论的核心素材，直接支撑「生物机制修复 JEPA 坍塌」的动机与合理性。
